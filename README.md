# ポケットマリオランナー（スマホ向け横スクロール）

スマホの Web ブラウザで遊べる、スーパーマリオ風の横スクロールアクションゲームです。タッチボタンまたはキーボードで走ってジャンプし、コインを集めながらゴールの旗を目指します。依存はなく、静的ファイルをそのまま配信するだけで遊べます。

## すぐ遊ぶ
リポジトリ直下で次のコマンドを実行すると、URL が表示されてプレビューサーバーが立ち上がります。

```bash
./preview.sh
```

- Local: `http://localhost:8000/index.html`
- 同一 LAN 内のスマホ: `http://<PCのIP>:8000/index.html`

停止するときは `Ctrl + C` を押してください。`PORT`/`HOST` 環境変数でポートやバインド先を変更できます。

### 手動で起動する場合
```bash
python -m http.server 8000 --bind 0.0.0.0
```
ブラウザで `http://localhost:8000/index.html` を開きます。クラウド環境ではポートフォワードを有効にし、発行された共有 URL をスマホで開いてください。

## 操作方法
- 右に進む/左に戻る: 画面下の ◀ / ▶ ボタン、またはキーボードの ← / →
- ジャンプ: ⤒ ボタン、またはキーボードの Space / ↑
- 端末を横向きにするとプレイしやすくなります。

## ゲームの特徴
- カメラがプレイヤーを追従する横スクロールステージ
- シンプルな物理挙動（重力・慣性・壁との当たり判定）
- コインの獲得数と経過タイムを HUD で表示
- スマホ操作を優先した大きめのタッチボタン
