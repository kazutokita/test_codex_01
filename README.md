# モバイル向けテトリス

スマホのブラウザで遊べるシンプルなテトリスです。タッチボタンで移動・回転・ソフトドロップができ、キーボード操作にも対応しています。

## 遊び方
1. `index.html` をブラウザで開くとゲームが始まります。
2. 画面下部のボタンで操作します。
   - ◀︎ / ▶︎ : 左右移動
   - ⟳ : 回転
   - ▼ : ソフトドロップ
3. リセットボタンでスコアと盤面を初期化します。

フィールドは 10x20、ラインを消すごとにスコアとレベルが上がり、レベルに応じて落下速度が速くなります。

## プレビュー（スマホでも確認する場合）
ローカルに依存はありません。そのまま静的ファイルを配信してください。

### 簡単スタート（URL を表示するスクリプト付き）
リポジトリ直下で次のコマンドを実行します。

```bash
./preview.sh
```

するとローカル用とスマホ共有用（同一 LAN 内）の URL が表示され、そのままサーバーが立ち上がります。デフォルトのポートは 8000 です。サーバー停止時は `Ctrl + C` を押してください。

### 手動で起動する場合
1. リポジトリ直下でサーバーを起動します。
   ```bash
   python -m http.server 8000 --bind 0.0.0.0
   ```
2. PC のブラウザから `http://localhost:8000/index.html` を開くとゲームが始まります。
3. 同じネットワークにあるスマホからは、PC の IP アドレスに置き換えてアクセスします（例: `http://192.168.0.10:8000/index.html`）。
4. クラウド環境の場合はポート 8000 をフォワードし、発行された共有 URL をスマホで開いてください。

プレイ感を確認するときは、タッチボタン（◀︎ / ▶︎ / ⟳ / ▼）を一通り押してブロックが動くことをチェックしてください。
